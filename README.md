# 🏝️ ShiftySearch — Универсальный AI-островок для браузеров

> **ShiftySearch** — легковесное, быстрое и кроссбраузерное расширение для **Chromium** (Chrome, Brave, Edge), **Firefox** и **Safari**, которое встраивает удобный плавающий мини-островок искусственного интеллекта прямо в веб-страницы.

## 🌟 Ключевые возможности

- 🎨 **Минималистичный дизайн (Черный и Белый + Свой цвет)**: Утонченный строгий дизайн без лишних отвлекающих элементов. Быстрое переключение между **Светлой** (чистый белый) и **Тёмной** (глубокий черный) темами в 1 клик прямо в шапке островка (☀️ / 🌙) или в настройках.
- 🌈 **Выбор цвета акцента (Color Picker)**: Пользователь может выбрать абсолютно любой цвет интерфейса (кнопки, ссылки, бейджи, свечение) через палитру или ввести свой HEX-код.
- 🏝 **Плавающий мини-островок (Shadow DOM)**: Изолирован от стилей открытого сайта. Работает поверх любых страниц (YouTube, Reddit, GitHub, поисковики, статьи), не ломая верстку сайта.
- ⌨️ **Вызов по сочетанию клавиш (Custom Hotkey)**: Открывайте и скрывайте островок одним нажатием. По умолчанию `Alt + Shift + S`. В настройках встроен интерактивный рекордер клавиш — вы можете задать любую комбинацию.
- 📐 **Мгновенная смена масштаба**: Был маленький, нажали хоткей — открылся на нужный вам размер! По умолчанию сочетание `Alt + Shift + Z` (или кнопка в шапке) мгновенно переключает островок между **Мини-режимом** и **Развернутым режимом**. Размеры обоих режимов настраиваются в пикселях.
- 🖱️ **Свободное перемещение (Draggable)**: Хватайте островок за шапку мышью и ставьте куда угодно. Расширение запоминает его координаты на экране.
- 🔗 **Поиск и ссылки в конце ответа**: Нейросеть не просто отвечает, но и формирует блок полезных кликабельных ссылок и источников (`[Название](url)`), оформленных в виде интерактивных карточек.
- 🤖 **Поддержка любой нейросети**:
  - **Google Gemini** (Gemini 2.0 Flash, Gemini 1.5 Pro)
  - **OpenAI** (ChatGPT, GPT-4o, GPT-4o-mini, o3-mini)
  - **OpenRouter** (Сотни моделей, включая Perplexity Sonar для поиска с источниками в реальном времени, DeepSeek, Claude, Llama)
  - **Anthropic Claude** (Claude 3.5 Sonnet, Haiku)
  - **Groq** (Сверхбыстрая генерация Llama 3.3 70B)
  - **DeepSeek** (DeepSeek V3, DeepSeek R1)
  - **Свой endpoint (Custom / Local)**: Подключение Ollama (`http://localhost:11434`), LM Studio, vLLM или любого OpenAI-совместимого прокси.
- 🖱️ **Контекстное меню (ПКМ «Спросить у ShiftySearch»)**: Выделите любой текст на странице, нажмите правую кнопку мыши и выберите «Спросить у ShiftySearch» — островок откроется с выделенным фрагментом и сразу выдаст объяснение с источниками.
- ⚙️ **Удобные настройки**: Быстрые настройки прямо внутри островка (иконка шестеренки) без отвлечения от страницы + отдельная полноэкранная страница с тестированием API-ключа.
- ⚡ **Стриминг и Markdown**: Ответ выводится по токенам в реальном времени, поддерживаются заголовки, списки, цитаты и блоки кода с кнопкой «Копировать».

## 🚀 Установка в браузеры

Готовые сборки уже лежат в папке `builds/` и упакованы в архивы `dist/`.

### 1. Chromium (Google Chrome, Brave, Edge, Opera, Vivaldi, Яндекс Браузер)

1. Скачайте репозиторий или архив `dist/shiftysearch-chromium.zip` (распакуйте его в удобную папку).
2. Откройте в браузере страницу расширений:
   - В Chrome: `chrome://extensions/`
   - В Brave: `brave://extensions/`
   - В Edge: `edge://extensions/`
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
5. Выберите папку `builds/chromium` из этого репозитория.
6. Готово! Иконка ShiftySearch появится в панели расширений.

---

### 2. Mozilla Firefox

1. Откройте в Firefox вкладку отладки: `about:debugging#/runtime/this-firefox`.
2. Нажмите кнопку **«Загрузить временное дополнение...»** (Load Temporary Add-on).
3. Выберите файл `manifest.json` внутри папки `builds/firefox/` (либо архив `dist/shiftysearch-firefox.zip`).
4. Расширение активировано и готово к работе!

---

### 3. Apple Safari (macOS)

Safari использует формат Safari Web Extensions:
1. Убедитесь, что установлен Xcode или инструменты командной строки (`xcode-select --install`).
2. В терминале выполните стандартную команду Apple конвертации:
   ```bash
   xcrun safari-web-extension-converter builds/safari --project-location ./safari-build --app-name ShiftySearch
   ```
3. Откройте созданный проект в Xcode и нажмите **Run** (Cmd + R).
4. В Safari откройте: **Настройки** → вкладка **Расширения** → отметьте галочкой **ShiftySearch**.
*(Если расширение разрабатывается без подписи разработчика, в меню Safari «Разработка» включите «Разрешить неподписанные расширения»).*

## ⌨️ Горячие клавиши по умолчанию

| Действие | Сочетание клавиш | Описание |
| :--- | :--- | :--- |
| **Открыть / Скрыть островок** | `Alt + Shift + S` | Мгновенно показывает или скрывает островок |
| **Сменить масштаб (Мини / Большой)** | `Alt + Shift + Z` | Переключает размер между компактным и развернутым |
| **Закрыть островок** | `Esc` | Быстро спрятать островок |
| **Спросить о выделенном тексте** | `Выделить` → `ПКМ` | Пункт контекстного меню «Спросить у ShiftySearch» |
| **Отправить запрос** | `Enter` | Отправка запроса в островке |
| **Новая строка** | `Shift + Enter` | Перенос строки в поле ввода |

> 💡 **Настройка под себя**: В настройках ShiftySearch вы можете нажать кнопку **«Запись»** и нажать любое удобное вам сочетание клавиш (например `Ctrl+Space`, `Alt+Q` и т.д.).

## 🔑 Где взять бесплатные API-ключи

1. **OpenRouter (САМЫЙ УДОБНЫЙ В РФ — РАБОТАЕТ БЕЗ VPN)**:
   - Получить ключ: [OpenRouter Keys](https://openrouter.ai/keys) (вход через Google/GitHub в 1 клик).
   - Включает бесплатные модели: `google/gemini-2.0-flash-exp:free`, `meta-llama/llama-3.3-70b-instruct:free`, `deepseek/deepseek-chat`.
2. **Google Gemini** (Требует VPN при использовании из РФ/СНГ):
   - Получить ключ: [Google AI Studio](https://aistudio.google.com/app/apikey) (при создании нажимайте *«Create API key in new project»*).
3. **Groq** (Сверхбыстрая Llama 3.3, требует VPN из РФ/СНГ):
   - Получить ключ: [Groq Console](https://console.groq.com/keys)
4. **OpenAI** (ChatGPT):
   - Получить ключ: [OpenAI Platform](https://platform.openai.com/api-keys)
5. **DeepSeek**:
   - Получить ключ: [DeepSeek Platform](https://platform.deepseek.com/api_keys)
6. **Anthropic Claude**:
   - Получить ключ: [Anthropic Console](https://console.anthropic.com/settings/keys)
7. **Локальные модели без ключа (Ollama)**:
   - Установите [Ollama](https://ollama.ai) и запустите модель: `ollama run llama3.2`
   - В ShiftySearch выберите провайдер **«Свой endpoint»** и укажите URL: `http://localhost:11434/v1/chat/completions`.

## 🛠️ Разработка и сборка из исходников

Если вы хотите внести изменения в код и пересобрать проект:

```bash
# Установка зависимостей
npm install

# Пересборка для всех браузеров (Chromium, Firefox, Safari)
npm run build

# Генерация иконок (при необходимости)
npm run generate-icons
```

Скрипт сборки автоматически скомпилирует модули через `esbuild`, оптимизирует стили и сформирует готовые папки в `builds/` и zip-пакеты в `dist/`.
